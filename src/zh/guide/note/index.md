## 编辑器

为了更好的编辑体验，PileaX 团队开发了基于 [Tiptap](https://github.com/ueberdosis/tiptap) 的编辑器 —— [Yiitap](https://yiitap.pileax.ai/zh/)。

| 特性           | 描述               |
|--------------|------------------|
| 🤖 **AI 赋能** | 内置 AI 功能，助力内容创作，提升工作效率 |
| 📝 **Markdown 友好** | 支持直接粘贴、复制 Markdown 内容 |
| 🤝 **协作** | 基于 Yjs 和 Hocuspocus 的协作编辑   |
| 📝 **Notion 风格编辑器** | 界面简洁，交互直观     |
| 🧩 **块级编辑** | 通过 **气泡菜单、悬浮菜单、主菜单、侧边菜单** 轻松操作内容     |
| ✨ **丰富的特性** | 内置 **15+ 定制扩展** & **50+ 组件**       |

## Markdown

| 特性             | 描述                               |
|----------------|----------------------------------|
| **编辑中使用 Markdown** | 在所见即所得界面中支持 Markdown 标记          |
| **导入导出**           | 支持导入导出 Markdown                  |
| **存储 Markdown**    | 数据库存储 Markdown 格式的笔记，方便 AI 大模型使用 |

## AI

PileaX 笔记提供丰富的 AI 能力：

| 特性    | 描述                        |
|-------|---------------------------|
| **AI 菜单** | 支持文本润色、扩写、缩写、丰富表情等        |
| **AI 块**  | 支持编辑器内根据提示词生成AI内容         |
| **AI 对话** | 支持编辑时 `AI 对话`，提供更加灵活的AI能力 |
