# 书架

在书架中，对电子书与纸质书进行管理，通过直观卡片与多维标记，助你清晰掌控阅读进度与状态。

## 视图

支持多种视图展示书：

| 视图       | 描述                             |
|----------|--------------------------------|
| **网格标题** | 网格布局，显示封面和书名                   |
| **网格**   | 网格布局，大卡片，只显示封面                 |
| **紧凑**   | 网格布局，小卡片，显示封面、书名和作者            |
| **列表**   | 列表布局，显示封面、书名、作者、出版社、出版年和最后阅读时间 |

## 类型

按类型对书进行筛选，基本类型包括：

| 类型      | 描述               |
|---------|------------------|
| **全部**  | 全部类型             |
| **图书**  | EPUB、MOBI等格式的电子书 |
| **PDF** | PDF格式的电子书        |
| **纸质书** | 纸质书条目            |

## 阅读状态

按阅读状态对书进行筛选，阅读状态包括：

| 类型     | 描述                   |
|--------|----------------------|
| **所有** | 全部                   |
| **未读** | 新添加书的默认状态            |
| **想读** | 需要手动设置               |
| **在读** | 打开电子书开始阅读后，会自动设置为此状态 |
| **已读** | 读完或手动设置              |
