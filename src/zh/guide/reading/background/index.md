# 阅读背景

完美的阅读体验绝不仅仅是“白纸黑字”。默认的黑白背景固然干净，但在长时间阅读时，高饱和度的纯色容易引发视觉疲劳，且缺乏空间层次感。

因此，选择合适的背景有助于提高阅读体验：
- 缓解视力疲劳：精心调配的背景图片、纹理或颜色能够有效折射和吸收屏幕光线，减少直射眼球的刺眼感。
- 营造阅读氛围：无论是读一本古典文学，还是品味现代小说，合适的背景能让你瞬间进入“沉浸阅读”的状态。
