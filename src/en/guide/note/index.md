## Editor
To deliver an optimal editing experience, PileaX team built [Yiitap](https://yiitap.pileax.ai/zh/), an editor based on [Tiptap](https://github.com/ueberdosis/tiptap).

| Feature                    | Description                                                              |
|----------------------------|--------------------------------------------------------------------------|
| 🤖 **AI-Powered**          | Built-in AI tools to streamline content creation and boost productivity  |
| 📝 **Markdown-Frend**      | Direct copy & paste of Markdown content                                  |
| 🤝 **Collaboration**       | Real-time collaborative editing powered by Yjs and Hocuspocus            |
| 📝 **Notion-Style Editor** | Clean interface with intuitive interactions                              |
| 🧩 **Block-Based Editing** | Manipulation via bubble menus, floating menus, main menus and side menus |
| ✨ **Rich Features**        | Packed with 15+ custom extensions and 50+ built-in components            |


## Markdown
| Feature          | Description |
|------------------|-------------|
| **Markdown Markups** | Markdown syntax support within the WYSIWYG interface |
| **Import & Export**  | Full Markdown import and export functionality |
| **Markdown Storage** | Notes are saved as native Markdown in the database for seamless LLM processing |

## AI
PileaX Notes comes with a comprehensive suite of AI features:

| Feature | Description |
|---------|-------------|
| **AI Menu** | Text polishing, expansion, summarization, emoji enhancement and more |
| **AI Block** | Generate AI content inline within the editor using custom prompts |
| **AI Chat** | Access persistent `AI Chat` while editing for flexible AI workflows |
