# Editor
PileaX integrates [Yiitap](https://yiitap.pileax.ai/zh/), an AI-powered Notion-style block-based rich text editor.

## Core Features

| Feature                    | Description                                                              |
|----------------------------|--------------------------------------------------------------------------|
| 🤖 **AI-Powered**          | Built-in AI tools to streamline content creation and boost productivity  |
| 📝 **Markdown-Frend**      | Direct copy & paste of Markdown content                                  |
| 🤝 **Collaboration**       | Real-time collaborative editing powered by Yjs and Hocuspocus            |
| 📝 **Notion-Style Editor** | Clean interface with intuitive interactions                              |
| 🧩 **Block-Based Editing** | Manipulation via bubble menus, floating menus, main menus and side menus |
| ✨ **Rich Features**        | Packed with 15+ custom extensions and 50+ built-in components            |

## More Features
| Feature  | Description |
|----------|-------------|
| **Text Diagram** | Mermaid diagram rendering support |
| **Math Formula** | Inline and block mathematical equations |
| **Multimedia** | Images, audio, video and 3D model embedding |
| **Code**     | Inline code and multi-line code blocks |
| **Multi-column** | Multi-column layout arrangement |
| **Embed**    | Embed local files, online videos and more |
| **Attachment** | File attachment uploads |
| **Emoji**    | Full emoji support |
