# Keyboard Shortcut

| Action   | macOS                    | Windows/Linux               |
|----------|--------------------------|-----------------------------|
| Settings | <kbd>⌘</kbd><kbd>G</kbd> | <kbd>Ctrl</kbd><kbd>G</kbd> |
| Search   | <kbd>⌘</kbd><kbd>P</kbd> | <kbd>Ctrl</kbd><kbd>G</kbd> |
