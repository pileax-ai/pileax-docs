# Bookshelf
Manage your e-books and physical books in the bookshelf. Intuitive card layouts and multi-dimensional tags help you keep track of your reading progress and status.

## Views
Multiple display layouts are available for your library:

| View | Description |
|------|-------------|
| **Grid Title** | Grid layout showing covers and book titles |
| **Grid** | Grid layout with large cards displaying covers only |
| **Compact** | Grid layout with small cards showing cover, title and author |
| **List** | List view displaying cover, title, author, publisher, publication year and last read time |

## Types
Filter books by type. Available types include:

| Type | Description                             |
|------|-----------------------------------------|
| **All** | All types                               |
| **Books** | E-books in EPUB, MOBI and other formats |
| **PDF** | PDF e-books                             |
| **Physical Books** | Entries for physical books              |

## Reading Status
Filter books by reading status:

| Status | Description                                        |
|--------|----------------------------------------------------|
| **All** | All statuses                                       |
| **Unread** | Default status for newly added books               |
| **Want to Read** | Manually assigned status                           |
| **Reading** | Automatically set once you read an e-book          |
| **Finished** | Mark automatically upon completion or set manually |
