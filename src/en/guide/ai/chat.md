## Conversations
Conversations are categorized by tasks. Generally speaking, start a new conversation when launching a completely new task or when the message history becomes overly lengthy.
- Start new conversation: Create independent conversation threads as needed.
- Favorite: Topics are sorted chronologically by default; you may favorite and pin important topics to the top.

## Message List
A single conversation can hold hundreds of messages with varying content lengths. PileaX provides TOC to quickly jump to any target message.

## Message
- Copy: Copy the full AI response in Markdown format.
- Create note: Save satisfying AI outputs by turning them into standalone notes.
